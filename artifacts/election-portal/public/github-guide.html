1
Create a Repository on GitHub First Time Only
Set up a place on GitHub to store your code
Go to github.com, click the + button in the top-right corner, then select New repository. Give it a name and click Create repository.
① github.com → Sign In
→
② Click + (top right)
→
③ New Repository
④ Enter repo name (e.g. my-project)
→
⑤ Click "Create repository"
2
Initialize Git in Your Project First Time Only
Turn your local folder into a Git repository
Open your terminal and navigate to your project folder, then run these commands:
Terminal
$ cd your-project-folder
$ git init
Initialized empty Git repository in .git/
💡 cd means "change directory." Replace your-project-folder with the actual path to your project, e.g. cd Desktop/my-app
3
Connect to Your GitHub Repository First Time Only
Link your local project to the remote repository
Copy the repository URL from GitHub (it looks like https://github.com/yourusername/my-project.git) and run:
Terminal
$ git remote add origin https://github.com/yourusername/my-project.git
💡 origin is just a nickname for your GitHub URL. You'll use this nickname when pushing code.
Every time you want to push new changes
4
Stage Your Changes Repeat Each Time
Tell Git which files you want to include
First, check what files have changed, then stage them:
Terminal
$ git status
On branch main
Untracked files: index.html, style.css
$ git add .
💡The . (dot) means "add ALL changed files." You can also add one file at a time: git add index.html
5
Commit Your Changes Repeat Each Time
Save a snapshot of your staged files with a description
Write a short message describing what you changed:
Terminal
$ git commit -m "Add homepage and styles"
[main (root-commit) a1b2c3d] Add homepage and styles
2 files changed, 45 insertions(+)
⚠️Always write a meaningful message — avoid vague messages like "stuff" or "changes". Good messages help you understand your history later.
6
Push to GitHub Repeat Each Time
Upload your committed changes to the remote repository
Send your commits up to GitHub:
Terminal
$ git push origin main
Enumerating objects: 3, done.
Writing objects: 100% (3/3), 512 bytes | 512.00 KiB/s, done.
Branch 'main' set up to track remote branch 'main' from 'origin'.
💡origin is the remote (GitHub), and main is the branch name. Your branch might be called master on older projects — use whichever applies.
Quick Reference — Every Push in 3 Commands
Terminal — copy & use every time
$ git add .
$ git commit -m "Your message here"
$ git push origin main

After pushing, visit your GitHub repository page to see your files live in the cloud.
